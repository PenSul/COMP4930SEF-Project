# Shared container register

Add the real objects we can access before the main collection. Check existing
entries before assigning a new ID. Each row represents one physical object or a
group of matching designs. Refer to the
[collection guide](../../docs/data-collection.md#2-what-we-mean-by-different-designs)
for examples and the agreed class boundaries.

For a new design, use an ID such as `m1_mug_01`: the prefix records who first
registered it. Other photographers reuse that ID for the same object or matching
design. Describe its shape, size, colour and packaging well enough for another
member to recognise it. List member IDs under access; collector IDs in the image
manifests record who actually took each photograph.

The table starts empty. Add actual entries and include register changes in the
photo contribution pull request. The CSV manifests remain the dataset's image
records; this table helps coordinate collection and group IDs.
